# 京东航空运维保障系统 - 功能文档

## 系统概述

京东航空运维保障系统是一个基于 Python + HTML/JS 的单页面 Web 应用，用于管理和监控京东航空的设备（维修部工具设备），提供设备定位、GPS 轨迹查询、视频播放等功能。

- **技术栈**: Python 3 (http.server) + Leaflet.js + 高德地图瓦片
- **端口**: 8788（默认）
- **核心文件**: mcs8_web_panel.py（约 76KB，单文件包含前后端）

## 页面布局

系统分为三大标签页：

### 1. 首页工作台 (Dashboard)

- **设备统计**: 显示设备总数、在线设备、离线设备、覆盖城市数量
- **快捷查询城市视频**: 点击城市按钮可快速查看该城市的视频录像
- 自动刷新（每30秒）

### 2. 指挥调度 (GIS监控)

#### 左侧边栏 - 设备列表
- **搜索框**: 支持按设备编号、名称、分组、城市、仓库地址搜索
- **在线筛选**: 全部 / 在线
- **设备分组**: 按维修部分组显示
- **设备卡片信息**:
  - 设备名称 / 编号
  - **GPS城市**（红色字体）- 通过GPS坐标离线解析获得
  - **仓库地址**（绿色字体）- 从工具查询Excel匹配获得，已去除"机场""基地""工具库"等后缀
  - 近3天历史城市记录
  - 在线/离线状态

#### 地图区域
- **地图引擎**: Leaflet.js + 高德地图瓦片（国内免费地图接口）
- **图层切换**: 高德地图（矢量）/ 高德影像（卫星）
- **设备标记**: 绿色圆点=在线，红色圆点=离线
- **点击设备/定位按钮**: 地图自动居中到该设备 GPS 位置并放大到14级，弹出信息窗
- **地图工具**: 汇聚显示、状态显示、距离测量、框选调度、圈选调度、电子围栏

#### 右侧面板 - 历史轨迹
- 输入设备编号
- 选择时间范围（默认近24小时）
- 查询轨迹按钮 - 获取近3天GPS轨迹
- 清除轨迹按钮
- 显示轨迹统计（轨迹点数、里程、最高速度）

#### 设备调度状态表
| 列名 | 说明 |
|------|------|
| 状态 | 在线/离线 |
| 设备编号 | WXB编号 |
| 设备名称 | JDTY编号 |
| 组 | 维修部 |
| GPS城市 | 红色字体，GPS解析城市 + 距离 |
| 仓库 | 绿色字体，工具库存地址 |
| GPS | 经纬度坐标 |
| GPS时间 | 最后GPS上报时间 |
| 最后上线 | 最后平台上线时间 |
| 操作 | 定位 / 轨迹 按钮 |

### 3. 应用功能 (文件管理/视频播放)

#### 视频播放区域
- **多窗口播放**: 支持同时播放多个视频
- **网格布局**: 1屏 / 4屏 / 9屏 切换
- **播放列表**: 显示已添加的视频，可点击播放
- **清空按钮**: 清空播放列表

#### 文件查询
- **文件类型切换**: 平台文件 / 设备文件
- **时间筛选**: 今天 / 近3天 / 自定义
- **时间类型**: 拍摄时间 / 上传时间
- **城市筛选**: 下拉选择城市
- **分组筛选**: 下拉选择分组
- **设备搜索**: 输入设备编号或名称
- **分页**: 25/50/100条每页

#### 文件列表操作
| 操作 | 说明 |
|------|------|
| 播放 | 在播放窗口中播放视频 |
| 下载 | 新窗口打开视频链接 |
| 添加 | 添加到播放列表 |
| 标记 | 标注功能（预留接口） |

## 数据来源

### 设备数据
- **MCS8 平台 API**: 通过 SDK 端口 7711 / API 端口 7712 获取设备列表
- **设备目录缓存**: device_catalog_cache.json（30秒TTL）
- **设备过滤**: 仅显示维修部（groupId=30000002）且设备名称以 JDTY 开头的设备

### GPS 城市解析
- **离线地理查找**: offline_geo/ 目录下的 WGS84→GCJ-02 转换 + 城市边界匹配
- 设备上传的 GPS 坐标为 WGS84 格式，自动转换为 GCJ-02 后查询
- 城市名称不显示"市"字

### 仓库地址
- **工具查询 Excel**: 工具查询结果1782054355162.xlsx
- 通过设备条形码匹配仓库号
- 自动去除"机场""基地""工具库""库"等后缀

### 地图瓦片
- **高德地图（矢量）**: webrd0{s}.is.autonavi.com/appmaptile
- **高德影像（卫星）**: webst0{s}.is.autonavi.com/appmaptile
- 均为国内免费公开接口，无需 API Key

## 注意事项

1. **编码**: 文件使用 UTF-8 编码，Python 文件不含 BOM
2. **openpyxl**: 加载 Excel 时不要使用 ead_only=True（会截断列数据）
3. **PowerShell**: 避免在 PowerShell 中直接操作 JS/CSS 中的特殊字符
4. **中文路径**: 项目目录包含中文名"视频系统改造"
5. **MCS8 服务**: 确保 MCS8 SDK/API 服务正常运行
6. **端口冲突**: 启动前检查 8788 端口是否被占用
