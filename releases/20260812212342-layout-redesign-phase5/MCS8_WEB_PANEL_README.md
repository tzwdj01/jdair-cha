# 京东航空运维保障系统 - 功能文档

## 一、系统概述

京东航空运维保障系统是一个面向视频记录仪的检查管理平台，主要用于维修质量检查、安全检查、外站/城市视频抽查等场景。系统基于 Python 标准库构建，以单文件 Web 应用的形式运行，通过浏览器访问。

### 技术栈
- **后端**：Python 3.14 + http.server.ThreadingHTTPServer
- **前端**：纯 HTML/CSS/JavaScript（无框架依赖）
- **地图**：Leaflet.js + 高德地图瓦片
- **数据来源**：MCS8 服务端 API + 日志文件解析 + 本地缓存

### 运行环境要求
- Python 3.10+
- MCS8 桌面客户端已安装并至少登录过一次（用于获取 SessionId 和 OSS 配置）
- 配置文件路径：`C:\mcs8_x64\LocalConfig.xml`

## 三、页面导航

系统包含三个主页面，通过顶部导航栏切换：

### 1. 首页工作台（默认）
- **设备统计卡片**：显示设备总数、在线数、离线数、覆盖城市数
- **城市快捷入口**：一键跳转查询指定城市的视频

### 2. 指挥调度
- **GIS 地图监控**：高德地图显示设备位置
- **设备调度状态表**：设备列表与操作按钮

### 3. 应用功能（文件管理）
- **视频查询**：按时间、城市、设备筛选录像文件
- **多路播放器**：支持 1/4/9 宫格同时播放多个视频

## 四、功能详细说明

### 4.1 侧边栏设备列表

侧边栏始终显示，包含：

#### 设备统计
- 设备总数
- 在线设备数
- 已定位设备数

#### 搜索与筛选
- **搜索框**：支持按设备编号、设备名称、组名称模糊搜索
- **在线筛选**：不限 / 仅在线

#### 设备树
- 按分组（维修部）展示设备
- 每个设备显示：在线/离线状态、设备名称、设备编号、当前城市
- 历史城市：近 3 天内出现过的城市列表

#### 设备筛选规则
- 仅显示 **维修部**（groupId=30000002）的设备
- 仅显示设备名称以 **JDTY** 开头的设备
- 当前约 **56 台**设备符合筛选条件

### 4.2 点击设备交互

点击侧边栏设备或调度表中的"定位"按钮：
1. 自动切换到"指挥调度"地图页面
2. 地图自动居中到该设备的 GPS 位置
3. 自动放大到 14 级
4. 弹出设备信息窗

点击调度表中的"轨迹"按钮：
1. 自动切换到地图页面
2. 自动填充设备编号到轨迹查询框
3. 执行轨迹查询

### 4.3 GIS 地图监控

#### 地图图层
- **高德地图**（默认）：标准矢量地图
- **高德影像**：卫星影像地图

#### 地图功能
- **汇聚显示**：将所有设备缩放到视野内
- **状态显示**：切换设备名称标签显示
- **距离测量**：（预留工具位）
- **框选调度**：（预留工具位）
- **圈选调度**：（预留工具位）
- **电子围栏**：（预留工具位）

#### 设备标记
- 在线设备：绿色圆形标记
- 离线设备：红色圆形标记
- 选中设备：加粗边框突出显示
- 点击标记：弹出设备详情信息窗

### 4.4 历史轨迹查询

查询条件：
- 设备编号（点击设备自动填充）
- 开始时间
- 结束时间

查询结果：
- 轨迹点数量（超过 2000 点自动抽样）
- 行驶里程
- 最高速度
- 起止时间
- 地图上显示红色轨迹线、绿色起点、红色终点

### 4.5 设备调度状态表

表格字段：
| 字段 | 说明 |
|------|------|
| 状态 | 在线/离线 |
| 设备编号 | 如 WXB303 |
| 设备名称 | 如 JDTY01822 |
| 组 | 维修部 |
| 城市 | 通过离线 GPS 城市边界查询获取 |
| GPS | 经度, 纬度 |
| GPS 时间 | 最后一次 GPS 上报时间 |
| 最后上线 | 最后一次活跃时间 |
| 操作 | 定位、轨迹 |

#### 城市识别规则
- 使用离线城市边界数据（`offline_geo/city_geo_lite_0p005.json.gz`）
- GPS 坐标自动从 WGS84 转换为 GCJ-02（高德坐标系）
- 城市名称不显示"市"字（如"北京"而非"北京市"）

### 4.6 文件管理（应用功能页面）

#### 查询条件
- **时间预设**：今天、近 3 天、自定义
- **时间类型**：拍摄时间、上传时间
- **城市筛选**：下拉选择设备所在城市
- **分组筛选**：下拉选择设备分组
- **设备搜索**：按设备编号或名称搜索
- **每页条数**：25 / 50 / 100

#### 文件列表
| 字段 | 说明 |
|------|------|
| 设备编号 | 设备标识 |
| 设备名称 | JDTY 编号 |
| 文件标题 | 录像文件名 |
| 文件类型 | 视频/普通文件 |
| 大小/时长 | 文件大小和视频时长 |
| 拍摄时间 | 录制时间 |
| 上传时间 | 上传到平台的时间 |
| 操作 | 播放、下载、添加、标注 |

#### 操作说明
- **播放**：在右侧多路播放器中播放视频
- **下载**：在新窗口打开视频下载链接
- **添加**：将视频加入播放列表并自动播放
- **标注**：记录检查入口（待扩展）

### 4.7 多路视频播放

#### 播放列表
- 支持添加多个视频到播放列表
- 播放列表显示序号和文件名
- 每项可单独播放

#### 多宫格播放
- **1 屏**：单个大窗口
- **4 屏**：2×2 网格
- **9 屏**：3×3 网格
- 每个视频有独立的关闭按钮
- 支持同时播放多个视频

### 4.8 首页工作台

#### 统计卡片
- 设备总数
- 在线设备数
- 离线设备数
- 覆盖城市数

#### 城市快捷入口
- 自动列出所有设备覆盖的城市
- 点击城市按钮跳转到文件管理页面
- 自动设置城市筛选和今日时间范围

## 五、后端 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 返回主页面 HTML |
| `/api/health` | GET | 系统健康检查（服务器配置、日志状态、Session 状态） |

| `/api/gps-track` | GET | GPS 轨迹查询 |
| `/api/inspection/list` | GET | 检查记录列表 |
| `/api/inspection/save` | POST | 保存检查记录 |
| `/play` | GET | 视频播放（重定向到 OSS 签名 URL） |
| `/leaflet.js` | GET | Leaflet 地图库 |
| `/leaflet.css` | GET | Leaflet 样式 |
| `/hls/*` | GET | HLS 视频流文件 |

## 六、数据来源

### 6.1 设备数据
- **主数据源**：MCS8 API `/api/GetDevListByGroupId`
- **补充数据源**：日志文件中的 `allDevOnline` 事件
- **缓存文件**：`device_catalog_cache.json`

### 6.2 GPS 数据
- **实时位置**：日志文件中的 `gpsUpload` / `gpsUploadList` 事件
- **历史轨迹**：MCS8 API `/api/GetGpsModelList`
- **城市识别**：离线城市边界查询（`offline_geo/` 目录）

### 6.3 设备状态
- **在线状态**：日志文件中的 `DeviceStatus` 事件
- **最后活跃**：日志文件中所有包含设备 ID 的事件时间戳

### 6.4 录像文件
- **平台文件**：MCS8 API `/api/GetRecordFileList`
- **视频播放**：OSS 签名 URL（AWS4-HMAC-SHA256）

## 八、已知限制

1. **MCS8 服务端依赖**：录像查询、GPS 轨迹查询等功能需要 MCS8 服务端在线
2. **日志文件依赖**：设备列表、在线状态、GPS 位置依赖 MCS8 客户端日志
3. **视频播放**：需要有效的 OSS 签名，签名有效期 15 分钟
4. **地图瓦片**：使用高德地图免费瓦片服务，可能有访问限制
5. **并发**：基于 Python 标准库 HTTP 服务器，适合小规模使用

## 九、常见问题

### Q: 为什么设备列表为空？
A: 检查以下几点：
1. MCS8 客户端是否已安装并至少登录过一次
2. `C:\mcs8_x64\LocalConfig.xml` 配置文件是否存在
3. 日志文件目录 `C:\mcs8_x64\log\` 是否有最新的日志

### Q: 为什么地图不显示？
A: 检查以下几点：
1. 浏览器是否能访问外网（高德瓦片服务器）
2. 是否有防火墙阻止访问 `webrd0*.is.autonavi.com`

### Q: 为什么录像查询返回空？
A: 录像查询需要 MCS8 服务端 API 可用。如果服务端未启动，查询会返回空结果（不会报错）。

### Q: 如何更改监听端口？
A: 设置环境变量 `MCS8_PANEL_PORT` 为所需端口号，然后启动程序。
